# MODIFI Dashboard

A trade finance dashboard built with **React**, **Next.js**, and **TypeScript** to help businesses manage trades, track shipments, monitor repayments, and streamline customer onboarding.

This project is inspired by my previous work at MODIFI, a B2B fintech platform focused on cross-border payments and trade finance.
